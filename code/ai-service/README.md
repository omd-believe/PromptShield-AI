# PromptShield AI Service & FLAN-T5 Integration

PromptShield AI is the privacy and prompt-optimization engine for the PromptShield-AI architecture. It provides deterministic PII detection, risk scoring, anonymization, and prompt optimization, with an optional candidate generation stage powered by `google/flan-t5-small`.

---

## 1. What FLAN-T5 Does in PromptShield-AI

FLAN-T5 operates strictly as an **optional candidate prompt rewriter**:
- **Candidate Generator Only:** Proposes concise rewritten phrasing for the prompt.
- **Never an Authority:** FLAN-T5 does not make privacy decisions, assess risk, or override security boundaries.
- **Always Protected:** Receives only pre-processed, anonymized prompt text (where sensitive entities are replaced with placeholders like `[PERSON]`, `[EMAIL]`, etc.).
- **Strictly Validated:** Every candidate generated by FLAN-T5 must pass multi-stage quality, constraint, and privacy leakage checks. If any check fails, the deterministic candidate is retained as a safe fallback.

### Model Selection
- Model: `google/flan-t5-small` (~300 MB weights, 77M parameters).
- Status: **Pretrained from Hugging Face Hub (not fine-tuned)**.
- Target Hardware: Compatible with laptop GPUs (e.g., NVIDIA GeForce RTX 3050 with 6 GB VRAM) as well as CPU-only environments.

---

## 2. Configuration & Feature Flags

FLAN-T5 is controlled via environment variables (configured in `app/config.py`):

| Variable | Default | Description |
| :--- | :--- | :--- |
| `FLAN_T5_ENABLED` | `false` | Master toggle. Disabled by default to protect baseline stability. |
| `FLAN_T5_MODEL_ID` | `google/flan-t5-small` | Hugging Face model repository or local directory. |
| `FLAN_T5_DEVICE` | `auto` | Execution target: `auto` (uses CUDA if available, else CPU), `cpu`, or `cuda`. |
| `FLAN_T5_MAX_INPUT_TOKENS` | `512` | Token limit for input prompt. |
| `FLAN_T5_MAX_NEW_TOKENS` | `192` | Maximum generated tokens. |
| `FLAN_T5_NUM_BEAMS` | `2` | Beam search count (deterministic generation, `do_sample=False`). |
| `FLAN_T5_TIMEOUT_SECONDS` | `20.0` | Max latency allowed before fallback triggers. |
| `FLAN_T5_MAX_CONCURRENT_REQUESTS` | `1` | Semaphore bounding simultaneous inference to protect VRAM. |
| `FLAN_T5_USE_ONLINE_DOWNLOAD` | `false` | Whether to download from Hub if not cached locally. |
| `FLAN_T5_MIN_SEMANTIC_SCORE` | `70.0` | Minimum lexical/semantic similarity required to accept candidate. |

## 3. How Fallback & Candidate Selection Work

```
User Prompt
    │
    ▼
[Preprocessor & Privacy Engine] ──(Blocked?)──> HTTP 422
    │ (Anonymized Prompt)
    ├──► [Deterministic Optimizer Candidate]
    │
    └──► [FLAN-T5 Candidate Generator] (if FLAN_T5_ENABLED=true)
              │
              ▼
         [Candidate Safety & Constraint Validation]
         - Placeholder preservation ([PERSON], [EMAIL])
         - Negation preservation (not, never, do not)
         - Security terms preservation (plaintext, untrusted)
         - Generic types preservation (Map<Integer, Integer>)
         - Numeric constraints (3 bullet points)
         - Output format preservation (JSON, Markdown)
         - Privacy leakage scan (no unmasked PII)
         - Semantic similarity threshold (>= 70%)
              │
         Passed all checks?
          ├── Yes ──► Accepted Candidate = FLAN-T5
          └── No  ──► Fallback to Deterministic Candidate
              │
              ▼
    [Grammar Correction & Final Leakage Re-scan]
              │
              ▼
    [Final PromptResponse]
    (optimization_strategy, model_used, model_candidate_accepted)
```

If FLAN-T5 is disabled, missing weights, times out, or throws an exception, the pipeline silently logs a warning and returns the safe deterministic candidate.

## 4. Running the Tests & Evaluation

### A. Run Normal Unit & Integration Tests (No GPU or Download Required)
All 291 tests run using mocks and never require network access or GPU:
```bash
source .venv/bin/activate
pytest -q
```

### B. Run Opt-In Real Model Smoke Test
Runs real inference against the cached or downloaded model weights on GPU/CPU:
```bash
RUN_FLAN_T5_SMOKE_TEST=1 pytest -s tests/test_flan_t5_smoke.py
```

### C. Run Comparative Benchmark Evaluation
Compares deterministic baseline vs. FLAN-T5 candidate generation across 8 representative synthetic cases:
```bash
# On GPU (CUDA):
python evaluate_flan_t5.py --device cuda

# On CPU:
python evaluate_flan_t5.py --device cpu
```

---

## 5. How to Disable Immediately If Needed

If FLAN-T5 causes latency regressions or unexpected behavior in production, set:
```env
FLAN_T5_ENABLED=false
```
The service will immediately bypass model loading and inference, operating 100% deterministically with sub-10ms response times.
